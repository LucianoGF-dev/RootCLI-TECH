# ROOTCLI Tech

Sitio web institucional de **ROOTCLI Tech**, una agencia especializada en el desarrollo de soluciones digitales para negocios.

El sitio presenta los servicios de la empresa, información de contacto y una propuesta de valor enfocada en ayudar a empresas a mejorar su presencia digital mediante desarrollo web, automatización y tecnología.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Responsive Design
- Google Fonts
- Font Awesome

---

## ✨ Características

- Diseño moderno y responsive.
- Navegación intuitiva.
- Sección de servicios.
- Información de la empresa.
- Llamados a la acción (CTA).
- Integración con WhatsApp.
- Optimización para dispositivos móviles.

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio.

```bash
git clone https://github.com/usuario/rootcli-tech.git
```

2. Ingresar al directorio.

```bash
cd rootcli-tech
```

3. Abrir el archivo `index.html` en cualquier navegador.

También puede utilizar una extensión como **Live Server** en Visual Studio Code para una mejor experiencia durante el desarrollo.
